# .github

> [Default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for all my repos.

Located in [`.github/`](/.github/). Used by GitHub for any of my repos that does not have its own file of that type.

Exceptions:

- [`.github/CODEOWNERS`](/.github/CODEOWNERS): Only applied to this repository. GitHub does not support a default `CODEOWNERS` file, so each repo must have its own copy.
